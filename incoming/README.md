# Import inbox

Upload existing add-on ZIPs or `.py` files here using GitHub's **Add file > Upload
files**, then ask Codex to import a named file. You can also attach the file in
chat and ask Codex to import it directly.

Files here are public but not included in Blender's feed. Do not upload secrets,
private client material or add-ons you do not have permission to redistribute.
Conversion is reviewed work, not blind automatic execution of a ZIP.
